# HomeBank Mobile 0.6 — phase 1

Publication GitHub Pages : téléverser **uniquement** les fichiers de ce dossier à la racine du dépôt existant. Ne jamais téléverser de fichier .xhb ni de données bancaires. L’application est un prototype non audité.

Sur Android : ouvrir la PWA, sélectionner une **copie** du fichier .xhb transférée par USB. Le XHB est lu dans la mémoire de l’application, sans être téléversé par le code fourni. Les données ne sont pas conservées entre les redémarrages : il faut recharger la copie XHB. La file « Saisie » est expérimentale et stockée séparément dans le navigateur : ne pas l’utiliser pour de vraies opérations à ce stade.

Ne pas confondre hébergement du code public (GitHub Pages) et stockage des données privées (téléphone). Vérifier les résultats avec HomeBank. Aucune synchronisation automatique.
